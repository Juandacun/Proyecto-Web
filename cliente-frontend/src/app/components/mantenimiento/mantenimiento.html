Reglas de Negocio Activas

El módulo de incidentes y mantenimiento opera bajo las siguientes restricciones automáticas:

RN-04: Bloqueo Automático
Cualquier incidente con severidad 'Crítica' cambia inmediatamente el estado del recurso a 'Bloqueado'.
RN-05: Liberación por Mantenimiento
Al finalizar una intervención técnica, el sistema restaura el recurso automáticamente a estado 'Disponible'.
